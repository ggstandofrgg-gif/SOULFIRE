# SOULFIRE — Fabric 1.21.4 / Java 21

Исходный Gradle-проект самостоятельного мода в духе тёмного фэнтези.

## Уже заложено в проект
- Блок костра: активация, лечение, восстановление голода и сохранение последнего костра.
- Персональные данные игрока в NBT: души, уровень, очки, характеристики, Искра, выносливость и состояние режимов.
- Серверная выносливость: расходуется при беге, восстанавливается в покое; прокачка выносливости увеличивает её максимум.
- RPG-прокачка: жизненная сила, выносливость, сила, ловкость, интеллект, вера, живучесть.
- Способности через команды: перекат, рывок, импульс Искры, очищение эффектов, усиление ёмкости Искры.
- Переключатели боевого режима, захвата и канатного режима.
- Возврат к последнему костру и восстановление потерянных душ.

## Команды
- `/soulfire help`
- `/soulfire stats`
- `/soulfire stamina`
- `/soulfire levelup`
- `/soulfire upgrade vigor` (или endurance/strength/dexterity/intelligence/faith/vitality)
- `/soulfire combat`
- `/soulfire roll`
- `/soulfire dash`
- `/soulfire wallgrab`
- `/soulfire rope`
- `/soulfire spark pulse`
- `/soulfire spark cleanse`
- `/soulfire spark crystal`
- `/soulfire warp`
- `/soulfire recover`
- `/soulfire souls <amount>` — только оператор.

## Сборка
Нужны JDK 21 и интернет для загрузки Gradle/Fabric зависимостей.

Linux / Termux (если установлен Gradle):
```bash
gradle build
```
Windows:
```powershell
gradlew.bat build
```

Готовый JAR будет в `build/libs/`.

## Важно
Это первая исходная версия-платформа. Выносливость уже рассчитывается на сервере, но отдельный клиентский HUD и синхронизация её значения для отображения ещё не добавлены. Здоровье и голод пока используют стандартные механики Minecraft. Автоматический wall-run, полноценная физика канатов, паркурные анимации, GUI костра, визуальные эффекты и выпадение душ при смерти требуют следующих итераций. Способности пока доступны через команды.
